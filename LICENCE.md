## ✨ Features

### ESP
- Loadout Switcher — swap between saved loadouts mid-session
- Show Target Info — visualize entity markers in the practice range
- Replay Notes — record and review mission runs
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### Wallhack
- Weapon Catalog — browse weapons, camos, reticles, attachments
- Custom Class Notes — organize saved classes and perks
- Marker Visibility — improved on-screen marker clarity

### Aimbot
- Practice Range Notes — segment study on any map layout
- Movement Note Panel — manually review movement states in the range
- Sprint Buffer Notes — chain complex maneuvers in practice
